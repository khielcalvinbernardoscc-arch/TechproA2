# Shopping List Project

**Author:** Khiel Calvin Bernardo  
**Language:** Java  

Description
A simple program that lets the user enter up to 5 shopping items,  
shows the list, counts the total items, and allows searching for an item.



Enter up to 5 items to buy:
milk
eggs
rice
soap
coffee
Your shopping list:
milk, eggs, rice, soap, coffee
You entered 5 item(s).
Search for an item: rice
✅ rice is in your shopping list!
